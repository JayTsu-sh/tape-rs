## 边界与暂缓项

- 明确不支持：硬链接；共享可写 mmap 无支持承诺；跨带原子 rename 返回 EXDEV。
- 可选改造：fsync 数据刷新与索引提交分离。当前保留数据和索引归档确认；仅在性能证据或应用需求支持时另行设计。
- 后续扩展：Follower 驱动器任务分发、多副本及离线副本选择，不属于首版遗漏。
- 物理设备待验证：[真机清单](real-hardware-checklist.md)。Holo/LE 结果不替代真实固件、断电及机械性能证据。
- 性能目标未知时只报告基线，不认定业务达标；[性能框架](performance-acceptance.md) 的历史“尚未运行”不否定已完成的目录基准。
- GitHub 推送仍须用户提出；本轮正式部署已获用户按顺序执行的授权。
