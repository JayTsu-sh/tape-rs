# RC0018L9 追加定位修复实机验收

2026-09-27 18:43 CST 完成。主机 10.131.4.143，IBM TD9 R3G0，驱动 serial 11EB4A80F1；Rust `/dev/sg3`，LE 同一 LU 的 `/dev/sg4`；机械手 `/dev/sg5`。direct I/O 全程关闭。使用同一 512KiB 变长记录、随机数据源、普通 sync 写 DP、会话结束补 IP。

## 功能结果

- Rust 写入 3145 文件、18256392448 字节，16 批次普通 sync，最终 generation 17。
- 正常卸载回槽、重载后，Rust 首轮和重复全量 SHA-256 均通过。
- 正常退出 Rust 流程后启动新 LE/FUSE 实例，重新分配卷。LE 两轮全量 SHA-256 均通过。
- 前序 LE 写入 → Rust 全量 SHA 也通过，构成双向交叉验证。
- 完成标志 `probes/results/physical-rc18-20260927/rc18-functional-performance.complete`，详细命令与进程流程在同目录 `rc18-followthrough.log`。
- 最终 LE 正常卸载、退出，PR 无持有者，RC18 回槽7，RC17 保持槽8。随后开始独立 sync 定位修复测试，当前设备状态以新测试日志为准。

## 性能结果与边界

| 项目 | 旧 Rust | 追加定位修复 Rust | LE 基线 |

| 256×4KiB 数据 / sync | 554.89 / 15.10 s | 26.26 / 19.93 s | 12.14 / 8.61 s |
| 2500×64B 数据 / sync | 未完成 | 18.33 / 16.21 s | 12.54 / 8.20 s |
| 16GiB 数据 / sync | 56.18 / 10.50 s | 64.23 / 10.63 s | 55.90 / 7.04 s |
| 写会话结束卸载（含 IP checkpoint） | 未完成 | 177.51 s（IP 49.81 s） | 175.92 s |
| 同盘重载 | — | 31.85 s | 移带及命名空间就绪 44.56 s |

小文件数据阶段约 21.1 倍加速，数据加 sync 总计约 12.3 倍。16GiB 单轮变慢，无证据归因为定位修改；需要后续重复测量，不宣称所有负载加速。

Rust 重载挂载耗时 348.41 s，之后实际读取 139.28 / 137.16 s；挂载包含历史索引链扫描。LE 新 FUSE 实例读 Rust 数据首轮 76.61 s（含按需挂载），第二轮 19.74 s，第二轮没有新增 SCSI 请求，是缓存命中。LE 自己写的数据另有冷读 80.44 s。不能将 LE 缓存读与 Rust 每次真实磁带读当成相同带速口径。

这轮覆盖同一盘装卸重载，**没有完成两盘跨带切换性能验收**。诊断 strace 与正式计时分开；旧 append 诊断确认重复 LOCATE 约 1.9s/文件。

## 软件验证

追加定位版全功能测试 244 passed / 0 failed / 7 ignored；check、Clippy `-D warnings`、fmt 通过。三处旧掉电夹具显式补入预期的持久化屏障，避免依赖冗余 LOCATE 的隐式 flush。兼容 glibc 2.34 的 release 构建成功，工具链外部 Zig 链接器弃用告警原样保留。

当前后续 sync 定位修复另有新增测试及实机流程，不以本报告替代它的验收。

## 普通 sync 与正常挂载后续验收（19:26 完成）

普通 sync 实时位置修复，独立追加3×32个4KiB文件，不覆盖旧文件、不格式化：三批数据/sync分别0.148/10.086s、8.130/13.803s、5.339/9.987s；补IP49.816s。重载挂载363.282s，3241文件两轮完整SHA通过（141.446/140.023s）。

随后用正常挂载快速路径版打开同一代20的卷，挂载124.856s，报告history_checked=false；追加32文件并sync到generation21。正常卸载重载挂载121.459s，3273文件两轮SHA通过（142.037/140.364s）。新的LE/FUSE实例重新分配卷，两轮3273文件SHA通过（66.063/19.665s；第二轮为缓存）。正常卸载退出，`sync-mount-functional.complete` 已留存。

因此挂载耗时约降至三分之一；这里仍保留双分区EOD/索引/追加位置检查，不能把125秒说成LE缓存挂载的同等成本。顺序read的重复定位优化尚未包含在这一独立候选中，读取时间作为后续对照。
