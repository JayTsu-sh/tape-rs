# 物理带库统一执行，逻辑带库划分业务资源

逻辑带库是 `tape-rs` 在一个物理带库内管理的资源划分。驱动器、存储槽位和 I/E 槽位各自独占分配，物理带库统一管理机械手、库存、设备所有权和 HA 接管。这样可以隔离 pool 业务，同时维持共享机械手的单一执行权和恢复边界。

此决定在物理带库启用逻辑带库后扩展 [ADR 0001](0001-library-pool-tape-management.md) 的归属层级。启用时，默认逻辑带库接纳原有 pool 和所需受管资源，保留已有 pool、介质与文件身份。启用后，已有和新建 pool 都在逻辑带库下处理业务，各操作使用所属逻辑带库的资源。未分配资源等待分配后才可参与业务。

现有物理带库首次启用安排维护窗口。切换前暂停目标库的新业务，结清原任务和未知机械结果，确认所有执行节点支持逻辑库隔离并核对库存。共享目录一次发布默认逻辑带库、既有 pool 归属和启用状态，所有业务入口以该状态为准。

物理库启用逻辑带库后，业务接口要求逻辑带库范围。客户端和执行节点在维护窗口统一切换，既有 pool 和数据通过一次性迁移接续。未启用逻辑带库的物理库使用 [ADR 0004](0004-physical-and-replicated-pools.md) 的直接归属规则。
