# 普通磁带池的归属与多副本池的提交条件

普通磁带池归属一个带库范围。物理库未启用逻辑带库时，直接承载普通磁带池。启用后遵循 ADR 0003，池归属逻辑带库，既有池在维护窗口随现有迁移流程保留身份并绑定到默认逻辑带库。这一决定替代 ADR 0003 对未启用逻辑带库时的新版业务准入限制。

多副本池使用一个对应用可见的文件命名空间。底层各池可在同一逻辑库、不同逻辑库，或尚未划分逻辑库的不同物理库内。每个底层池仍按所属物理库授权执行。同一物理库内的多个副本共享设备故障范围。

多副本池在全部底层池均完成同一版本的完整磁带提交后才发布新写入的版本并确认归档成功。选择全副本确认是为了让写入回执直接证明约定的副本数量。单库失联会延迟该池的写入确认，已发布版本仍可从可用且验证通过的副本读取。恢复继续使用原任务及各已确认副本的提交证明。

创建时可从现有 LTFS 磁带导入文件目录，保留原卷和原文件内容。导入版本按实际验证的副本数提供访问与状态，创建成功证明导入完成。其余副本由管理员按需求另行安排。不同介质的同路径文件内容冲突时，创建任务暂停并报告各自来源，交由管理员处理。
